# Icons

Outline icons from [Tabler Icons](https://tabler.io/icons) (MIT licence, © Paweł Kuna), fetched from the
`@tabler/icons` npm package (`icons/outline/<name>.svg`) and rendered to transparent PNGs with macOS QuickLook
(`qlmanage`), stroke recoloured to `#0A0A0A`. Used on the hands-on slide: chart-area-line, chart-scatter,
users-group, terminal-2, message-chatbot, users, book-2; on the discussion slide: list-check, file-text, notebook, key, telescope.
